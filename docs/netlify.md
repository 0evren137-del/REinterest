# Netlify 部署与迁移

生产网址：https://chimerical-cocada-675f82.netlify.app 。2026-10-21 已公开，未登录请求首页与应用脚本返回 200。

## 首次部署（Free 套餐）

1. 注册并登录自己的 Netlify 账号，选择 Free 套餐。
2. 在项目根目录运行 `npm run build:netlify`。
3. 打开 https://app.netlify.com/drop ，上传 `deploy/netlify` 文件夹，或使用项目根目录生成的 `REinterest-netlify.zip`。
4. 等待部署完成，保留生产网址。确认项目是公开访问的；用未登录浏览器测试。
5. 页面完成验证后再将这个固定网址发给朋友。

代码仓库部署也可使用根目录 `netlify.toml`，构建命令为 `npm run build:netlify`，发布目录为 `deploy/netlify`。无需数据库、云函数、第三方 npm 依赖或付费域名。免费套餐当前有用量上限，具体规则以账号控制台为准。

## 数据和代理

- 原 Sites 网页、本地 localhost 和 Netlify 网页属于不同网址，浏览器数据不会自动同步。先在旧网址导出 JSON，再在新的固定网址导入。导入会替换目标记录。
- 所有资产记录仍使用 localStorage，不上传到 Netlify 数据库。共用浏览器配置的人共用记录。
- Netlify 版本从本站 `/api/exchange-rates` 获取汇率，Netlify 按 `_redirects` 转发到固定的 Frankfurter v2 接口。只包含公开币种和日期，不包含资产金额、名称或账户。
- 此服务端转发与用户设备上的 VPN/网络代理不同。切换普通网络代理通常不会改变同一网址的本地记录，但网络可能影响页面及汇率请求。无痕或不同浏览器配置会使用不同存储。
- 测试阶段及后续更新应坚持同一生产网址；不同部署预览网址属于不同存储空间。
- 安全响应头限定脚本、样式和网络请求来源为本站。包只包含页面文件、响应头及汇率转发规则。
