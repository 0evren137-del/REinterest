# 有数 · REinterest

离线个人资产手账。按自己的节奏记录资产快照，查看国内 / 国外、储蓄 / 投资的分布与区间收益。

当前版本：**v0.1**（2026-10-21），第一个调试完成的正式基准版本。后续修改从此版本继续。

## 第一次运行

本机已安装 Node.js。无需下载任何依赖，无需 npm install，也无需联网。

1. 双击本文件夹中的 **打开有数.vbs**，自动启动后台服务并打开可用网页，无需复制网址，也无需保留命令窗口。
2. 服务已运行时会直接打开网页，重复点击不会重复启动服务。原来的 **start.bat** 也支持自动打开。
3. 添加资产，然后进入“记录资产”，保存第一份快照。
4. 下次仍使用同一个浏览器、同一个网址打开。
5. 关闭网页即可结束本次使用；后台服务保留到电脑关机或重启。下次双击“打开有数”即可继续，关闭网页不会删除已保存的资产记录。

可以右键“打开有数.vbs”→“发送到”→“桌面快捷方式”，以后直接从桌面双击打开。

也可以在 VS Code 的终端运行：

```powershell
npm start
```

`localhost` 和 `127.0.0.1` 对浏览器来说是不同的数据存储空间。请固定用 **http://localhost:4173**，不要切换端口、网址或浏览器。

## 数据到底存在哪里

- 资产数据保存在浏览器的 **localStorage**，不是源代码目录，也不是云端数据库。
- 关闭网页或本地服务后数据仍保留；清理网站数据、使用无痕模式或换设备会影响可用性。
- 在“备份与指南”导出 JSON，保存在自己的安全位置。备份是明文文件。
- 导入先做格式校验，再确认替换现有数据。建议导入前先导出原数据。
- 示例模式与个人记录隔离，退出示例会恢复个人记录。
- 本地服务只监听电脑的回环地址，手机不能直接连接。界面已适配手机，跨设备访问及同步在云端版完成。
- 平时离线使用，不接银行或券商，没有第三方脚本或网络字体。只有点击“联网更新汇率”时，本地服务才向 Frankfurter 请求公开的币种与日期，不上传资产金额或账户信息。

## 一键更新汇率

在“记录资产”顶部点击 **联网更新汇率**，填入记录日期当日或之前最近可用的人民币参考汇率。来源：[Frankfurter](https://frankfurter.dev/)，免费、无需账号或 API 密钥；属于每日参考价，并非实时交易或银行结算价。按钮旁显示实际参考日期，节假日可能沿用此前数据。

常用币种精确到 0.01，小于 1 的汇率（例如日元）保留四位，均按“1 单位外币 = 多少人民币”填写。获取后点击 **保存修改的资产** 才生效，也可以只保存汇率而不修改资产金额。更新汇率会影响人民币折算总额，原币金额与金额更新日期保持原值；历史快照不会被批量修改。

网络失败会保留原值，仍可手动输入。请求期间手动改过的汇率也会保留。旧版本服务需要重启 start.bat 后刷新网页。

## 日常怎么记录

1. 在“我的资产”建立清单，可自定义账户、分类；国内 / 国外与币种相互独立。
2. 第一次只填想记录的资产金额及相关汇率，作为基准；其他资产留空，不会被记成 0。
3. 之后只修改想更新的资产，点击“保存修改的资产”。未修改的资产沿用之前金额，保留实际金额更新日期；未录入的新资产继续跳过。不涉及的外币无需填写汇率。
4. 转入为正、转出为负。内部转账要同时记录两侧。资产内未转走的买卖不记资金进出。
5. 清仓但希望保留历史时，金额记为 0，填写转走的资金。也可以在“我的资产”直接删除整项资产。
6. 已派到资产外的现金利息 / 分红单独填写；留在资产金额中的分红不要重复填写。
7. 同一天可以分多次更新，每次合并修改项，不覆盖其他资产已保存的金额和资金进出。
8. 首次录入某项资产时，没有填写资金进出就建立独立金额基准，不把整笔金额误算为收益；若填写了实际投入，可据此估算新增后的收益。

在“我的资产”修改名称、地区、类型、分类或所在账户后，资产总览的明细与三层分布立即同步，无需再记录金额。已保存的历史快照仍展示当时的信息。
修改资产资料不会新增快照、改动金额、收益或金额更新日期；以后创建新快照时，会采用当时最新的资产资料。

## 分层查看资产分布

总览的“资产明细”、“我的资产”和“记录资产”均提供同样的分层分类检索：大类 → 自定义分类 → 所在账户。
可以叠加名称、分类、账户或币种关键词搜索，查看匹配数量，或一键清除筛选。
三处沿用同一筛选路径，方便从总览明细、资产管理直接切换到对应资产的金额录入。
总览仅检索已有金额的资产明细，筛选不会改变总资产、收益、趋势图或分布图；历史快照的查看表格也不受当前检索影响。
记录页切换筛选不会重建录入表单，已填金额、资金进出、派息和汇率保持不变；保存会包含所有已修改项，含暂时被筛选隐藏的修改，页面会提示其数量。

- 第一层显示国内储蓄、国内投资、国外储蓄、国外投资。
- 点击圆环扇区或右侧大类，进入第二层，按该大类的自定义分类汇总，例如 BTC、美股、黄金。
- 继续点击分类进入第三层，按“所在账户或平台”查看金额。例如“国内储蓄 → 活期 → 微信 / 支付宝 / 招行”；同一账户下同类资产合并展示。
- 想分别查看不同存放地点，请把它们建为不同资产，将分类统一为“活期”，分别填写所在账户为“微信”“支付宝”“招行”。
- 三层百分比和扇区大小都使用**全部资产的人民币折算总额**作为分母。国外投资占总资产 40% 时，细分可能为 BTC 10%、美股 20%、黄金 10%，不会重新放大成 100%。
- 展开时，其他大类、其他分类淡化保留在圆环原来的位置。第三层的账户比例也始终以总资产为分母。点击路径中的大类返回第二层，点击“全部资产”返回第一层，也可点击淡色扇区切换。
- 相同分类的资产自动合并，跨币种先按当前快照汇率折算；百分比显示到一位小数，合计可能有四舍五入差异。
- 各层占总资产不足 1% 的正金额项目合并为一个“其他”，圆环和明细列表同步收拢；恰好 1% 的保留。判断使用未四舍五入的实际比例。
- 点击“其他”进入下一层直接查看小项，不再次合并；可以继续进入原来的大类、分类或账户。路径保留“其他”，可逐层返回。
- “其他”的金额和扇区为小项之和，展开后分母仍是总资产。小于 1% 的比例显示更多小数；零金额资产不占分布扇区，可在“我的资产”中查看。

新增资产会出现在下一次录入中；任何资产都可以删除，包括已经记录金额的资产。
删除前会确认：该资产在全部历史快照中的金额、资金进出和派息会一起删除，历史总资产和收益随之重新计算；其他资产与快照日期保留。
删除不能直接撤销，可以通过删除前导出的备份恢复。已有历史的资产仍不能更换币种。
录入中的改动需要点击保存，切换页面或关闭页面会提示；目前没有自动保存草稿。

## 收益口径

```text
本期原币收益 = 期末价值 − 期初价值 − 期间净投入 + 已派出收益
加权本金 = 期初价值 + Σ(每笔资金进出 × 距期末天数 / 区间天数)
区间收益率 = 本次更新原币收益 / 加权本金
```

- 使用 Modified Dietz 估算区间收益率，不是年化，也不是精确的时间加权收益率或 XIRR。
- 现金派息按期末发生处理；金额大、期间长或复杂交易可能有估算误差。
- 期末当天投入的权重为 0；加权本金不大于 0 时不显示收益率。
- 首份快照只建立基准，不显示区间收益。
- 首页“资产变化”包含新增资金和汇率变化。
- 每项资产的收益区间从它上次实际更新金额的日期开始，不受其他资产更新日期影响。
- 未更新的资产显示沿用的金额日期，收益率显示“未更新”，不伪造新估值或零收益。
- 首页“本次更新资产收益”仅汇总当天实际更新项，各项收益区间可能不同；按本次汇率折算，含储蓄利息、不含汇率损益，不是整个组合的人民币总回报。
- 总资产包含沿用的旧金额；修改某币种汇率会影响快照中该币种全部资产的人民币折算价值。
- 当前支持非负资产估值，不支持负债、空头、杠杆和交易逐笔核算。
- 本工具用于个人估算查看，以银行、券商账单为核对依据。

## 项目结构：以后接云端怎么改

```text
web/
  index.html       网页入口
  styles.css       电脑 / 手机布局
  app.js           页面交互
  domain.js        数据校验、快照、收益计算
  repository.js    数据保存接口，目前是 LocalRepository
server.mjs         仅用于本机提供网页文件
tests/             计算与存储测试
```

界面通过 `load / save / import / export` 接口访问数据。以后新增云端 Repository，在登录后替换适配器即可复用大部分界面与计算。
云端阶段仍需要实现用户认证、数据库权限、同步冲突处理及数据迁移；并非只修改一个网址。
当前 JSON 包含版本号与资产唯一编号，方便后续迁移。
